## 📌 Sobre Nós

Bem-vindo ao GitHub oficial do **Ministério Bezalel**. Este espaço foi criado para centralizar, organizar e versionar todos os projetos de software, sites e ferramentas tecnológicas desenvolvidos pelos membros do nosso ministério de TI para a Igreja.

### Nosso Propósito
Utilizar a engenharia de software e a tecnologia como ferramentas para a expansão do Reino de Deus. Assim como Bezalel foi capacitado com habilidades técnicas e criativas para construir o Tabernáculo, nós dedicamos nossos dons para apoiar as operações da Igreja Batista da Graça, otimizando processos e criando soluções que sirvam à nossa comunidade.

> *Consulte o arquivo `README.md` individual de cada repositório para ver as instruções de instalação local e a stack técnica específica.*

## 🤝 Como Contribuir

Se você é membro da Igreja Batista da Graça e atua ou estuda na área de tecnologia (desenvolvimento full-stack, design, infraestrutura ou gestão de projetos), sua ajuda é muito bem-vinda!

1. Solicite acesso à nossa organização no GitHub conversando com a liderança do ministério.
2. Navegue pelos repositórios e busque por *issues* abertas (rotuladas como `good first issue` ou `help wanted`).
3. Crie uma branch para sua funcionalidade ou correção (ex: `feature/nova-tela-cadastro`).
4. Desenvolva, faça os testes e envie um **Pull Request** detalhando as alterações implementadas.

## 📫 Contato e Suporte

Para sugestões de novos projetos, dúvidas técnicas ou reporte de bugs nos sistemas atuais:
- Abra uma **Issue** no repositório do projeto correspondente.
- Procure a equipe do Ministério Bezalel presencialmente ou nos canais oficiais de comunicação da igreja.
